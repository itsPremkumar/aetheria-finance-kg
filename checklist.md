# AI Governance Checklist — Self-Assessment

Use this checklist to assess your AI system's governance readiness before deployment.

## Pre-Deployment Checklist

### Data & Privacy
- [ ] Data source inventory complete
- [ ] Privacy impact assessment (DPIA) conducted
- [ ] Consent mechanisms verified
- [ ] Data retention policy documented
- [ ] Anonymization/pseudonymization applied where required

### Model Fairness
- [ ] Protected attribute analysis performed
- [ ] Disparate impact ratio > 0.8
- [ ] Bias mitigation strategy documented
- [ ] Fairness metrics benchmarked against baseline
- [ ] Cross-group performance parity verified

### Transparency & Explainability
- [ ] Model explainability method selected (SHAP, LIME, integrated gradients)
- [ ] Explanation quality validated with stakeholders
- [ ] Model card published
- [ ] Documentation includes limitations and known failure modes

### Safety & Robustness
- [ ] Adversarial robustness testing completed
- [ ] Out-of-distribution detection implemented
- [ ] Fallback strategy defined
- [ ] Performance thresholds documented

### Operational Controls
- [ ] Model monitoring dashboard configured
- [ ] Alert thresholds set for key metrics
- [ ] Rollback procedure tested
- [ ] Incident response plan in place
- [ ] Access controls enforced (RBAC)

### Compliance
- [ ] Regulatory classification determined (EU AI Act risk tier)
- [ ] Legal review completed
- [ ] Audit trail logging enabled
- [ ] External audit scheduled (annual)

## Governance Review

- [ ] AI Governance Committee review scheduled
- [ ] Model Review Board approval obtained
- [ ] Ethics sign-off documented
- [ ] Escalation path communicated to all teams
